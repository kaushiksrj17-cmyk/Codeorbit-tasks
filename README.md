# Codeorbit Tasks

This repository contains internship task submissions for Codeorbit.

## Projects Overview

| Task | Project Name | Description | Tech Stack |
| :--- | :--- | :--- | :--- |
| **Task 1** | [Rule-based Chatbot](./Rule_based_Chatbot/) | Rule-based conversational chatbot with pattern matching & Streamlit UI | Python 3, Streamlit |
| **Task 2** | [Tic-Tac-Toe AI](./Task2_Tic_Tac_Toe_AI/) | Interactive Human vs AI Tic-Tac-Toe featuring an unbeatable Minimax algorithm | HTML5, CSS3, JavaScript |
| **Task 3** | [Image Classification AI](./Task3_Image_Classification/) | Real-time image classification using pretrained MobileNetV2, top-3 confidence scoring & Dark Mode | Python 3, PyTorch, TorchVision, Streamlit |

---

### How to Run Task 1 (Rule-based Chatbot)

#### Terminal Interface:
```bash
cd Rule_based_Chatbot
python chatbot.py
```

#### Streamlit Web App:
```bash
cd Rule_based_Chatbot
streamlit run app.py
```

---

### How to Run Task 2 (Tic-Tac-Toe AI)

#### Direct Browser Launch:
Open `Task2_Tic_Tac_Toe_AI/index.html` directly in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

#### GitHub Pages:
Once enabled under repository **Settings > Pages**, access the live application directly online.

---

### How to Run Task 3 (Image Classification AI)

#### Setup & Launch:
```bash
cd Task3_Image_Classification
pip install -r requirements.txt
streamlit run app.py
```
